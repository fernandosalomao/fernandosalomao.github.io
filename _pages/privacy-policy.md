## Overview

This is a personal blog operated by Fernando Salomao at [fernandosalomao.com](https://www.fernandosalomao.com). I don't collect personal information directly, but third-party services used on this site may do so as described below.

## Analytics

This site uses **Google Analytics 4** to understand how visitors interact with the content — including which pages are visited, approximate geographic location (country/city level), browser and device type, and how visitors arrive at the site.

Google Analytics uses cookies and similar tracking technologies to collect this data, which is sent to and stored on Google's servers. You can learn more about how Google uses this data at [google.com/policies/privacy/partners](https://policies.google.com/technologies/partner-sites).

**To opt out**, you can install the [Google Analytics Opt-out Browser Add-on](https://tools.google.com/dlpage/gaoptout) or use a content blocker such as uBlock Origin.
